# Configure options before saving a snapshot

## Description

Add a collapsible Options panel to Save a page. Pass the selected options through the shared frontend API to the backend's existing crawl configuration.

## Specs

- Offer recursive crawling, maximum link depth, and same-domain restriction.
- Start with recursion off, depth 1, and same-domain restriction on. Enable the latter controls when recursion is selected.
- Keep choices in the current window and restore defaults in a new window.
- Freeze the submitted options while saving. Preserve the URL and options on failure, and allow saving the same URL again after an option changes.

## Requirements

- Reuse the existing Qt Designer layout, archive service, and `/snapshots/create` endpoint.
- Keep existing calls compatible and omit crawl configuration when recursion is off.
- Use the backend's existing depth and domain rules.

## Acceptance criteria

1. Options starts collapsed. Recursion is off and its dependent controls are disabled. Expanding and reopening the panel preserves choices in that window.
2. Saving with recursion enabled sends `crawl.enable`, `crawl.depth`, and `crawl.top_level_only` through the UI, archive service and shared API. Saving with defaults preserves the original request body.
3. Options cannot be edited during a save. Failure restores editing and keeps the input. Changing an option after success enables another save of the same URL.
