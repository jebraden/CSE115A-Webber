# Wire backend archive exporting to the frontend

## Description
Adds functionality to the UI allowing one to request the snapshot collection to be 
archived and exported. This allows the User to be able to backup their data at will
or share it with others.  
  
## Specs
Design is subject to change
- Clicking the 'export-all' button sends the backend request with body '{"archive": "ALL"}'
- Clicking the export button on the snapshot view page sends the backend request with body '"archive": <snapshot-id>'
- Clicking either button first opens a dialog where you select the destination of the export
- The request is actually sent upon selecting the file destination as described above

## Requirements
- Follow established conventions in the frontend
- Follow established error handling convention
- Add frontend functionality to central UI. No new frontend view

## Acceptance Criteria
- Clicking 'export-all' button sends the request to the backend with '{"archive": "ALL"}' after download path confimation
- Clicking 'export' button in a snapshot view sends the request backend with '{"archive": <snapshot-id>}'  after download path confirmation
