# Extend Page Scraper to handle hyperlink scraping

## Description
The Page Scraper needs to be extended so we may recursively scrape a page. This is done so that while viewing a page, we may click on the hyperlinks
present in that page.  
  
## Specs
- HyperlinkRules define max recursion depth and also rules for what domains are allowed to be scraped. That is Top level domains, a white list to
bypass that filter, and a blacklist in case you are not filtering top level domains.
- hyperlink discovery occurs at the end of a page scraping job, so long as that page's depth is less than the hyperlink rule's stated max depth.
- Page elements that define a hyperlink (specified from the html spec page) become candidates for processing
- The candidates must also pass the rules defined by the PageScraper's hyperlink rules
- For each passing url, we then start a child PageScraper with all the same settings rules, and saved urls as the current one. The depth of the child
scraper is incremented by 1.

## Requirements
- All old behavior must be preserved
- Nothing new to store in the database


## Acceptance Critera
- max depth property of HyperlinkRules enforced
- whitelist and top level domain only behaviors enforced
- blacklist behavior enforced
- saved url set is carried on over to the child Scraper to avoid infinite looping / redownloads
